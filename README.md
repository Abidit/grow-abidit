# Abidit Shrestha - Portfolio

A professional, modern portfolio website converted from a senior engineer brag document. Built with a focus on impact, readability, and clean design.

## Features

- **Modern Aesthetic**: Dark mode with indigo/emerald accents, glassmorphism navigation, and smooth animations.
- **Dynamic Achievements**: Automatically renders achievement cards from data, highlighting 'What', 'How', and 'Impact'.
- **Interactive Elements**: Custom hover effects, scroll reveal animations, and smooth navigation.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **SEO Ready**: Semantic HTML5 structure with optimized meta tags.

## Tech Stack

- **Vite**: Ultra-fast frontend build tool.
- **Vanilla JavaScript**: Lightweight and performant logic.
- **Vanilla CSS**: Custom-built design system without heavy frameworks.
- **Google Fonts**: 'Outfit' for a modern, premium feel.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## Project Structure

- `index.html`: Main structure with sections for Hero, Achievements, About, and Contact.
- `style.css`: Design system, layouts, and animations.
- `main.js`: Rendering logic for achievement cards and interaction handling.
- `package.json`: Project configuration and dependencies.
